# 3D assets for the Home intro

The models and HDRI below come from [Poly Haven](https://polyhaven.com) under its
[CC0 license](https://polyhaven.com/license). Texture sizes are optimized for the web.

| File | Poly Haven asset | Used for |
|---|---|---|
| planter_pot_clay/ | Planter Pot Clay, https://polyhaven.com/a/planter_pot_clay | the tapered terracotta pot (colour map dropped, relief kept) |
| potted_plant_02/ | Potted Plant 02, https://polyhaven.com/a/potted_plant_02 | the scanned soil |
| fern_02/ | Fern 02, https://polyhaven.com/a/fern_02 | archived fern model |
| cloudy_netted_nursery_1k.hdr | Cloudy Netted Nursery HDRI, https://polyhaven.com/a/cloudy_netted_nursery | image-based light |
| arch_nor_gl.webp | Clay Plaster (normal map), https://polyhaven.com/a/clay_plaster | archived plaster relief |

The arch, greenhouse, and leaf textures are derived from the supplied scrolling reference.
The greenhouse depth map was generated locally with [Depth Anything V2 Small](https://github.com/DepthAnything/Depth-Anything-V2).
The desktop and portrait fallback posters are renders of the opening scene.
